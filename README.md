# Simple Interest Calculator

## Overview
A simple program that calculates simple interest on a principal amount.

## Formula
Simple Interest (SI) = (P × R × T) / 100

- **P** = Principal amount
- **R** = Annual rate of interest (%)
- **T** = Time period (in years)

## How It Works
1. The user enters the principal, rate, and time.
2. The program applies the formula.
3. The program displays the simple interest.

## Example
Principal = 1000, Rate = 5%, Time = 2 years
SI = (1000 × 5 × 2) / 100 = **100**

## Usage
Run the program and enter the requested values:

    python simple_interest.py
